# 신뢰성 측정 기록 (PWA)

부품 특성치(최소 동작전압, 유량, rpm, UV 조사량, 소비전류 등)를 한 화면에서 입력·타이머·판정·집계하는 앱입니다.
설치 후 인터넷 없이도 동작하며, 데이터는 기기 브라우저에 저장됩니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소 생성 (예: `rel-log`)
2. 이 폴더의 파일 5개를 업로드: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 후 `https://<아이디>.github.io/rel-log/` 접속

## 폰에 앱으로 설치
- **Android (Chrome)**: 메뉴 ⋮ → "앱 설치" 또는 "홈 화면에 추가"
- **iPhone (Safari)**: 공유 버튼 → "홈 화면에 추가"

## 주요 기능
- 기본 시료 수(n) + 시험 단계별 시료 수 개별 지정, 측정 중 ＋/－ 버튼으로 즉시 조정
- 시험 단계(초기/환경시험 후/내구시험 후 등), 측정 항목과 기준(LSL/USL) 등록
- 측정 화면: 큰 숫자 키패드, 입력 즉시 OK/NG 색상 판정, 다음 시료 자동 이동, 항목 완료 시 다음 항목 자동 전환
- 같은 화면에 0.1초 단위 타이머(카운트다운/스톱워치) + 현재 시각(초) — 유량 1분 측정용, 3·2·1 비프 & 종료 알림
- 🎤 음성 입력: "내열 1, 백오십" → 내열 후 #1 시료에 150 기록 / "고온고습 2번 4.8 볼트" → 단위로 항목 자동 전환 / "사 점 팔" → 현재 칸 기록 / "취소" "다음" "시작" "정지"
- 빠른 입력칸: "내열1 150" 입력 후 Enter (폰 키보드의 마이크 받아쓰기도 사용 가능)
- 측정 화면 상단 시험 단계 버튼 줄: 단계 → 시료 칸 → 값 입력 (화면 전환 없음)
- 블루투스/USB 숫자 키패드: Enter 기록, Space 타이머, Esc 지우기, Ctrl+Z 취소
- 평균·최소·최대·σ·Cpk·NG 수, 단계별 비교와 초기 대비 변화율, 산점도 차트
- CSV(엑셀 호환) 원시/요약 내보내기, 엑셀 붙여넣기용 복사, 메신저 공유, JSON 백업/복원
- 시료별 메모, 실행 취소, 부품 복제(새 Lot), 화면 꺼짐 방지, 다크 모드

## 주의
데이터는 브라우저 저장소에만 있습니다. 브라우저 데이터 삭제 시 사라지므로 **설정 → 전체 백업**을 주기적으로 해 주세요.
수정 후 다시 올릴 때는 `sw.js`의 `rel-log-v4`의 숫자를 하나씩 올려 바꾸면 캐시가 확실히 갱신됩니다.
